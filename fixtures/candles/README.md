# fixtures/candles

**SYNTHETIC TEST DATA — NOT REAL MARKET DATA**

Every CSV file in this directory is generated by a deterministic, seeded
pseudo-random-number generator (never `Math.random()`, never sourced from a
real broker/exchange feed). Prices, timestamps, and volumes here do not
describe the behavior of any real instrument and must never be presented as
real market data anywhere in the product (dashboard, reports, docs, etc.).

## Format

Each file is a plain CSV with a header row and one candle per data row:

```
timestamp,open,high,low,close,volume
2024-06-01T00:00:00.000Z,100.00,100.06,98.05,99.02,189.81
```

- `timestamp`: ISO-8601 UTC datetime string.
- `open`, `high`, `low`, `close`, `volume`: plain decimal strings (no
  scientific notation, no thousands separators).

This matches `csvCandleRowSchema` and `CSV_CANDLE_HEADER` in
`packages/shared-types/src/csv-candle.ts`, and the invariants enforced by
`packages/database/src/candle-importer.ts` (`high >= open`, `high >= close`,
`high >= low`, `low <= open`, `low <= close`, `volume >= 0`).

## Files

- `synthetic-example-1h.csv` — ~100 hourly candles, starting
  `2024-06-01T00:00:00.000Z`. A small, human-inspectable fixture meant for
  manually exercising the candle import path (e.g.
  `POST /market-data/import` once that endpoint exists in `apps/api`),
  without needing to hand-write CSV rows.

## Why this exists

Milestone 1 needs real end-to-end plumbing (CSV -> validation -> Postgres ->
backtester) that can be exercised by a human before any live market-data
feed is wired up. This file lets you manually POST a small, known-good CSV
and see rows land in the `Candle` table. The larger synthetic dataset used
for the default dev seed (800+ hourly candles, enough to warm up EMA(50) and
ATR(14)) is generated in code by `packages/database/prisma/seed.ts` rather
than checked in here, to keep the repo small.
